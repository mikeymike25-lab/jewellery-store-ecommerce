# Source-to-Ionic Coverage Matrix: Éclore Jewellery Store
**Document:** `migration-audit/02-source-to-ionic-coverage-matrix.md`  
**Target Architecture:** Laravel 12 Backend API + Ionic 8 Vue 3 Frontend  
**Audit Date:** October 11, 2026  
**Auditor:** Senior Application Migration Auditor & QA Lead  
**Audit Status Definitions:**
- **FULLY MIGRATED:** In-scope UI, navigation, behavior, backend integration, relevant authorization, and expected states are implemented; supporting evidence exists.
- **PARTIALLY MIGRATED:** Some meaningful parts exist, but one or more required actions, states, validations, integrations, or roles are missing.
- **PLACEHOLDER / MOCK ONLY:** Screen or behavior uses static/hardcoded/demo data or inert controls instead of the expected live behavior.
- **IMPLEMENTED BUT DISCONNECTED:** Code exists, but routes, navigation, API wiring, guards, or actions do not connect to it correctly.
- **MISSING:** Required in-scope screen/module/workflow has no substantive target implementation.
- **BROKEN / FAILING:** Evidence shows a build/runtime/navigation/API/functional failure.
- **INTENTIONALLY OUT OF SCOPE:** Excluded by a documented scope decision; cite that decision.
- **NOT VERIFIABLE:** Available evidence is insufficient to confirm status.
